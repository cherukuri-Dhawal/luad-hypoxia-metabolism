# TCGA LUAD hypoxia and metabolism research pipeline

A complete, runnable computational research project: patient preparation → Hallmark Hypoxia ssGSEA → tertile groups → expression exploration → clustering → gene/pathway analysis → honest model comparison → survival analysis. No independent cohort has been validated yet.

## Start with the results

Open **results/report.html** in a browser. It is self-contained and works offline. It explains the actual computed results, includes plots and states the limits. Read **RESULTS_QUICKSTART.md** for the key numbers. The model predicts an expression-derived hypoxia group, not measured oxygen or a clinical diagnosis.

## Run it yourself

Python 3.11 or later is recommended. Create a virtual environment, then run:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python download_data.py
python pipeline.py
python verify.py
```

The large public TPM matrix (~169 MB compressed) is not duplicated inside this archive. `download_data.py` retrieves it directly from UCSC Xena and records input checksums. Allow enough disk space for the decompressed matrix in memory and dependencies. The source data have 60,660 gene identifiers × 589 samples. This project was run on CPU with two numerical-library threads. Runtime varies by machine; UMAP can need compilation on its first run.

**Do not run an untrusted joblib/pickle file.** The included frozen model is generated by this project's code; it requires the matching packages and the local `model.py` module to load. Regenerate it using the scripts if preferred.

## What every stage does

1. **Prepare data.** Use the Xena log2(TPM+1) matrix; do not log-transform again. Select primary tumors by sample barcode `01`, verify clinical sample labels and match IDs. Choose the lexicographically first sample per patient, independent of expression/outcomes. Retain all 516 unique patients unless a quality check fails. Average duplicate-symbol log-expression rows using the same deterministic rule for new data. Preserve source identifiers and selection decisions in audit files. No unexplained outlier removal.
2. **Score hypoxia.** User-supplied MSigDB Hallmark Hypoxia v2026.2: 200 genes, 199 direct matches. HACL2 is omitted and documented, not silently renamed. Run GSEApy ssGSEA with rank normalization, rank correlation weights and exponent 0.25. Use raw ES, never cohort-dependent NES, for frozen scoring. Score universe and parameters are saved. ssGSEA needs a broad background, so this stage does not restrict to the top 5,000 genes.
3. **Make research groups.** Full-cohort descriptive tertiles yield 172 patients per group. Predictive folds and the final test instead use cutoffs calculated only on their training/development patients. Cutoff ties follow `<= low`, `>= high`, otherwise intermediate.
4. **Explore.** Use up to 5,000 variable genes outside the scoring signature. Scale genes, fit PCA, and show a scree plot and PC1/PC2 scatter. ICA, t-SNE and UMAP provide extra views. Full-cohort exploratory transforms are never fed into predictive evaluation. No claim that a separated 2D view proves biological subtypes.
5. **Cluster.** Use 20 PCA components (variance reported), scaled for the clustering distance. Compare K-Means K=2–8, choose K by silhouette rather than label agreement, and assess seed stability. Compare hierarchical and DBSCAN results. Count original hypoxia groups inside clusters; report silhouette, ARI and AMI. Hypoxia labels are not provided to clustering.
6. **Compare biology.** Descriptive filter: log2(TPM+1) ≥ 1 in at least 10% of selected tumors. Compare high versus low tumors using Welch tests; report Mann–Whitney results separately as sensitivity analysis. Apply BH correction within each family. Report mean differences on the log2(TPM+1) scale, not misleading raw-count fold changes. Threshold used for the descriptive gene list: FDR < 0.05 and absolute difference ≥ 0.5. Flag and exclude scoring genes from the primary differing-gene list. These full-cohort gene results are not used to preselect ML features.
7. **Analyze metabolic pathways.** Nine prespecified Hallmark metabolic/related sets: glycolysis, oxidative phosphorylation, fatty-acid metabolism, cholesterol homeostasis, bile-acid metabolism, peroxisome, adipogenesis, reactive oxygen species and mTORC1 signaling. ORA uses the actually tested background minus scoring genes; higher/lower directions are tested separately and jointly FDR-corrected over the 18 tests. Pathway ssGSEA scores and their Spearman associations omit overlapping hypoxia genes. These are expression associations, not measurements of biochemical flux.
8. **Train classifiers.** Predict high/low labels from the fixed union of the nine metabolic/related sets minus all hypoxia-scoring genes (917 input genes). Reserve 104 patients (20%) before predictive fitting. Compare six methods on 412 development patients using common five-fold outer splits and three-fold inner tuning. Fit expression prevalence/variance filters, scaling and supervised selection inside training folds. Up to 5,000 training-variable features are permitted; the fixed metabolic input space is smaller. Keep up to 150 predictive genes. Evaluate logistic regression, linear/RBF SVM, random forest, XGBoost and kNN. Select using development outer-fold AUC; fit the selected model on development extremes only. Freeze it before evaluating 69 high/low patients in the untouched test set; the 35 intermediate test patients are not included in the binary metrics. Include dummy and clinical-only baselines and a patient-bootstrap AUC interval. No model is selected using test metrics.
9. **Study survival.** Verify OS=1 death, OS=0 alive/censored, and time in days against the clinical fields. Exclude invalid/nonpositive follow-up. Plot KM curves and test the three groups with a log-rank test. Fit an exploratory Cox model with continuous hypoxia per SD, age, sex and categorical stage; check proportional hazards. Also fit a stage-and-sex-stratified sensitivity model because nuisance-covariate PH violations can affect the simple adjusted model. Report missingness and complete-case denominators. This is an association analysis, not a validated patient survival predictor.
10. **External validation.** NOT YET RUN. An independent LUAD cohort is required. LUSC would be a secondary cross-subtype transfer experiment, not a direct replacement for same-disease validation.

## Apply the frozen model

`external_validate.py` accepts a gene-symbol × sample TSV (optionally gzip), already in log2(TPM+1) units. It freezes gene ordering, preprocessing, model, ssGSEA background, scoring weights and development cutoffs:

```bash
python external_validate.py --expression independent_luad.tsv.gz \
  --unit 'log2(TPM+1)' --independent-patients --out external_results
```

The validator requires every symbol in the frozen scoring background and rejects missing background genes, nonfinite expression and source sample IDs. It will not silently impute missing genes, change the score universe or relabel a new cohort by its own tertiles. For microarray or differently annotated cohorts, a prospectively defined common-gene scoring and training protocol is needed; do not interpret failed strict compatibility as biological failure. A successful independent-cohort run is not included in the delivered results.

## Files your team will use

- `pipeline.py`: biological analysis, preprocessing, scoring, exploration and orchestration.
- `model.py`: nested predictive evaluation and the frozen training-only pipeline.
- `survival.py`: KM, Cox, diagnostics and stratified sensitivity analysis.
- `download_data.py`: public-input retrieval and SHA-256 provenance.
- `external_validate.py`: strict, independent-cohort prediction entry point.
- `verify.py`: independent score-formula check, patient split, inference and output checks.
- `Team_Walkthrough.ipynb`: simple notebook to run the scripts and inspect saved outputs.
- `results/patient_scores_and_clinical.csv`: each patient's selected sample, score, group and clinical fields.
- `results/differential_expression.csv.gz`: all tested genes and both test results.
- `results/metabolic_pathway_enrichment.csv`: directional pathway ORA with corrected p-values.
- `results/pathway_hypoxia_associations.csv`: pathway-score associations after removing scoring genes.
- `results/frozen_model.joblib`: selected frozen model and its complete scoring contract.
- `results/untouched_test_predictions.csv`: each eligible final-test patient's prediction.
- `results/summary.json`: structured run summary; `verification_checks.json`: scientific checks.

## Interpretation limits

The target label and input features come from the same RNA experiment. Removing scoring genes reduces direct circularity but cannot make the label an independent oxygen measurement. Strong classifier performance is evidence of a reproducible expression relationship within this cohort, not experimental hypoxia validation. Extreme-group classification is easier than classifying the full continuum. Gene/pathway association tests remain influenced by correlated expression and potential tumor purity, cell-composition, stage, treatment and smoking confounding. Cox models and bootstrap intervals are exploratory. No causal claims, treatment recommendations, validated diagnostic biomarkers or clinical deployment are justified.

## Provenance and reuse

Exact input URLs and SHA-256 hashes are in `provenance.json`; package versions, random seed and protocol are saved in results. Public Xena/GDC data and MSigDB gene sets retain their providers' terms; cite TCGA, UCSC Xena, MSigDB/Hallmark, GSEApy and lifelines in a thesis or presentation. The included gene sets are the downloaded reference lists, not patient measurements. Original user Counts are unnecessary for this TPM-based run.

## Expanded classifier benchmark

Run `python compare_more.py` after `python pipeline.py` to compare eight additional classifiers: Extra Trees, histogram gradient boosting, AdaBoost, gradient boosting, Gaussian naive Bayes, shrinkage LDA, elastic-net logistic regression and SGD logistic regression. The combined table compares 14 classifiers using the same outer development folds. The original frozen model is preserved. Results of the expanded comparison are exploratory because the original holdout has already been inspected. Use development CV for ranking and obtain an independent cohort before confirming a new winner. K-Means, hierarchical clustering and DBSCAN are reported separately using cluster metrics, not classification AUC.
